# Consulting library: tool list v2 (for approval)

This is the list to paste into **Admin > Tools marketplace > Add tools**, consolidated for the consulting library.
Nothing here has been drafted yet; each name costs about one AI call to draft, and every draft is reviewed by you before it joins the library.

- **Part 1 (existing names):** the 142 tools from your course decks, with the ones the Strategy Hub already has by hand removed (RACI Matrix, Balanced Scorecard, OKR (Objectives and Key Results), Blue Ocean Strategy, BCG Matrix, Ansoff Matrix, PEST Analysis, Porter's Value Chain, Scenario Planning, Value Proposition Canvas).
- **Part 2 (proposed additions):** names added to fill the Process, Digital, Technology, Organisation, Programme and change, Finance and risk, and Strategy practices. Strike out any you do not want before pasting.
- Headings set the group, and the group places each tool in a consulting practice (Auto). The 36 hand-built Strategy Hub tools are added separately with one button and are not in this list.
